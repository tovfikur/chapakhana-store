[**Chapakhana (ছাপাখানা)**](https://chapakhana.store) is Bangladesh's premier commercial printing press and packaging atelier, delivering high-precision corporate stationery, e-commerce packaging suites, waterproof vinyl stickers, and all-in-one business launch packages across all 64 districts of Bangladesh.

Operating under the design philosophy of **high-end craftsmanship + modern fashion e-commerce + transparent BDT pricing**, Chapakhana replaces chaotic traditional print shops with a seamless digital platform featuring transparent volume tiers, luxury imported cardstocks, tactile hot foil finishing, and nationwide fulfillment.

## 🛠️ Technology Stack & Engineering Architecture

- **Web Framework**: [Next.js 15 (App Router)](https://nextjs.org/) with React 19 & TypeScript
- **Styling & Design Tokens**: Tailwind CSS with custom dark atelier and warm ivory color palettes
- **Database**: PostgreSQL 16 on Docker (`chapakhana_db`) with discrete production jobs pipeline
- **Edge Deployment**: Docker Standalone Container connected to Cloudflare Edge via persistent Cloudflare Tunnel
- **Search Engine Protocols**:
  - Google Indexing API (`URL_UPDATED` instant publish)
  - IndexNow Protocol (Bing, Yandex, Seznam instant push)
  - XML Sitemap (`/sitemap.xml`) & RSS 2.0 Feed (`/feed.xml`)
  - Schema.org JSON-LD (`PrintingService`, `Product`, `AggregateOffer`, `BreadcrumbList`, `FAQPage`, `MerchantReturnPolicy`)
  - Geographic Local SEO: ISO BD-13 (Dhaka, Bangladesh: 23.7937, 90.4066)
